# PipeClean\n\nPipeClean is a Game Boy static-recompilation and runtime project for bringing classic Game Boy software to modern desktop hardware.\n\n## What is it?\n\nThe project combines an SM83 disassembly/recompilation toolchain with a lightweight runtime for video, audio, input, cartridge banking, and game execution. The current development target is **Super Mario Land 2: 6 Golden Coins**, with modern widescreen presentation as a primary feature.\n\nPipeClean is source-first: commercial game ROMs are supplied locally by the user and are **not included in this repository**.\n\n## Current focus\n\n- 16:9 / widescreen rendering\n- Correct object/entity activation in the extended viewport\n- Game Boy cartridge banking, including MBC1\n- SDL2 desktop runtime\n- SM83 recompilation and interpreter fallback\n- A maintainable Windows build/release workflow\n- Clear documentation for users and contributors\n\n## Status\n\n| Area | Status |\n| --- | --- |\n| Runtime | In development |\n| SM83 tooling | Working prototype |\n| SML2 MBC1/interpreter path | Implemented |\n| SML2 widescreen activation fix | Implemented + regression-tested |\n| Windows release build | Needs final local/CI verification |\n| Launcher UX | In development |\n| Documentation | Active |\n\n## Documentation\n\n- [Installation](INSTALL.md)\n- [Architecture](docs/ARCHITECTURE.md)\n- [Legal information](LEGAL.md)\n- [Contributing](CONTRIBUTING.md)\n\n## Legal\n\nPipeClean is an independent project.
