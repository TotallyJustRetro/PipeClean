# HANDOFF (PipeClean / Dr Mario Launcher) — SM83 static recompiler + SDL launcher for Dr. Mario, Super Mario Land (SML), SML2
- **Done:** C lifter+runtime (`runtime/`), launcher UI (`launcher.c`, `ui.c`), 3 game tabs, palettes, bg images/GIF, romhacks (IPS/BPS/UPS), texture packs+export, filters, controls, DualSense (LED/rumble/speaker/events), menu music/SFX, Windows exe built via llvm-mingw (Linux-tested only).
- **Widescreen:** PPU renders up to 256px (`ppu_set_wide`, `widescreen.c`); per-game slider in Display tab; gates show bars on menus/maps. SML works: 235px, in-memory ROM patches (spawn +16k px at 0x24A5/0x24C0, despawn window at 0x2584, trampolines at 0x3FE4) – verified no mid-screen pop-in. SML2 now widens the entity activation high bound by the configured right extension at bank 2:$401C through an interpreter hook, preserving the ROM and instruction stream.
- **SML2 implementation:** entities live in SRAM slots AD00+0x20; activation window is computed in bank 2 @0x4000 (`LD DE,$0060` ±96px around cam FFCA/FFCB); `ADD HL,DE` at 0x401C is intercepted as `ADD HL,$0060+R`. Despawn window ±0xA0 remains unchanged. This avoids a risky variable-length ROM trampoline. The supplied SML2 ROM is 512 KiB MBC1; its bank-2 bytes confirm `$401C = ADD HL,DE`. The hook passes the regression test. Full gameplay/pop-in verification is still pending because this build environment has no SDL2 development headers.
- **Decisions:** ROM never modified on disk; patches verify expected bytes else fall back to normal screen; wide gate SML = IE timer bit, SML2 = window HUD wx==7&&wy==0x88; ROMs/generated code not committed (copyright) – regenerate: `python3 tools/recomp.py roms/dr_mario.gb -o generated --listing`; mapper ROMs use `--interp-only` (the Makefile selects this automatically for ROMs >32 KiB).
- **Build:** `make ROM=roms/dr_mario.gb BUILD=build_sdl SDL_LIBS=-lSDL2`; Windows: llvm-mingw + `EXTRA_LIBS="-lshell32 -lole32 -lcomdlg32 -luuid"`.
- **Dev tools:** `--headless --frames N --script s --wide PCT --dump-ppm/--dump-ram/--watch LO-HI`, `GBL_POPIN=xmin` pop-in detector, `tools/dis.py rom start end bank`, UI shots via `GBL_SHOT/GBL_TAB/GBL_SIZE` + dummy SDL drivers.
- **Files in play:** runtime/{ppu.c,widescreen.c,launcher.c,app.c,games.h,rom.c,emu.c,main.c,settings.c}, tools/{recomp.py,dis.py}, README.md.
- **Tested:** SML2 bank-2 `$401C` hook regression; supplied ROM identifies as MBC1 and contains opcode `0x19` there.
- **Untested:** full SDL SML2 gameplay/pop-in after the new hook, real-Windows audio smoothness, DualSense hardware, SML GIF animation wiring, Blargg regression after refactor.
